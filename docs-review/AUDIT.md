# Проверка и исправления, 13.10.2026

## Исправлено

- Отрицательное время из смешения epoch и performance.now: новый таймер от старта конкретной попытки, не от открытия сайта.
- Нет бонуса за пустую попытку/скорость. Нельзя отправить незавершённый тест.
- Нет подсказки через текущий счётчик правильных ответов. Ответы и время фиксируются после завершения.
- Имена и команды экранируются. Некорректные записи исключаются.
- Повреждённый localStorage и недоступность Firebase не блокируют теорию и тесты.
- Пустые страницы заменены переходами в наполненные разделы, исправлена инструкция GitHub Pages.
- Основной интерфейс больше не зависит от CDN Tailwind, React или Babel.
- Ожоги: не менее 20 минут охлаждения. Уточнены частичное/полное удушье, агональное дыхание, боковое положение, детские особенности и границы помощи с лекарствами.

## Источники и ограничения

Минздрав России, актуальная страница учебного комплекса 05.03.2026; пособие 2025; приказ 220н. Подписанное положение Карелии 2026 просмотрено визуально (титул, п.5, п.8, п.9). Подробные форматы заданий и станции основаны на типовом проекте правил 2026, вариант 1. Подписанные правила Карелии с чек-листами не были доступны. Авторские вопросы не являются официальным банком чемпионата. Текстовые наблюдения не заменяют видеозадания.

## Проверка

9 автоматических проверок на каждый репозиторий: наполнение, перемешивание, подсчёт, формат репетиции, пустая попытка, таймаут, фиксация результата, время и повреждённое хранилище. node --check для скриптов, git diff --check.

Общий Firebase-рейтинг предназначен только для учебного сравнения. Существующее подключение чтения подтверждено в браузере. Новые правила firestore.rules подготовлены, но не применены в Firebase Console. Отправка новых данных в рабочую базу тестовой записью не выполнялась.
