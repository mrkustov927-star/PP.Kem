# Первая помощь — подготовка команды, 2026

Статический тренажёр для школьников 14–17 лет, Кемь / Карелия. 16 тем, 94 вопроса с объяснениями, 18 ситуаций, 8 наблюдений и 3 практические станции. Авторские учебные задания не являются заданиями чемпионата.

## Запуск и публикация

GitHub Pages: Settings → Pages → Deploy from a branch → main → /root. Сборка и npm не нужны. Все основные зависимости локальные: assets/content.js, municipal.js, core.js, app.js, style.css. Открыть локально можно через `python3 -m http.server 8000`. Старые theory.html, examples.html и test.html направляют в соответствующие разделы.

## Режимы

Перед запуском любого режима обязательны имя/псевдоним и команда. Поля с одними пробелами не принимаются. Введённые данные сохраняются отдельно для каждой попытки и показываются в результате, личной истории, экспорте и при публикации в рейтинге. Изменение профиля во время прохождения не меняет владельца уже начатой попытки.

Тренировка: до 6 вопросов парами по теме, немедленная проверка и объяснение каждого ответа; после проверки ответ нельзя изменить. Фильтры по теме и слабым темам. Контроль: 20 вопросов / 20 минут. Муниципальная репетиция: 10 вопросов по восьми компетенциям + 3 ситуации с одной оценкой целиком + 2 текстовых наблюдения на 3 и 7 оценок / 25 минут. Учебный максимум 39 балла, веса 1/3/2; текстовые наблюдения не заменяют официальное видео и их чтение включено в таймер. Повторение ошибок использует вопросы из последних 10 попыток.

Таймер стартует при запуске, ответы и время фиксируются после завершения. Без ответов ручное завершение запрещено; по таймауту отсутствующие ответы считаются неверными. Никаких бонусов за скорость.

## Источники

Медицинские алгоритмы: учебное пособие Минздрава, Москва, 2025, и приказ №220н. Прямые ссылки и печатные страницы в карточках. Подписанное положение Карелии 2026 подтверждает школьную категорию, состав команды, дистанционный муниципальный и очный основной этап в Медвежьегорске. Подробности заданий и практические чек-листы сверены с типовым проектом правил 2026, вариант 1; подписанная редакция правил Карелии с чек-листами не предоставлена. Это ограничение явно указано на сайте.

## Хранение и Firebase

Личная история и профиль сохраняются в localStorage (`pp_preparation_v2`), доступны экспорт JSON и очистка. Некорректные/старые записи не ломают приложение. Отключение хранилища сопровождается сообщением.

Общий учебный рейтинг в PP.Kem подключается только по запросу пользователя. Конфигурация существующего проекта в assets/config.js. Отображаются только новые записи schemaVersion=2 текущей версии и режима среди последних 100 записей коллекции attempts. Старые записи не удаляются и не смешиваются. HTML-поля выводятся с экранированием. Новые попытки публикуются автоматически после завершения; до старта участнику показано уведомление о публикации имени/псевдонима, команды и результата. Отправка требует завершённой попытки и полного профиля; ID документа совпадает с ID попытки. Рейтинг вычисляется на клиенте, поэтому не пригоден для официального отбора.

`firestore.rules` — рекомендованный ограничивающий набор правил для новых записей; он НЕ применяется публикацией сайта. Перед применением проверьте остальные коллекции: отсутствующие match запрещают доступ. Требуются Anonymous Auth и права на чтение/создание в attempts. Нет доступа к Firebase Console в рамках этой проверки; фактическое применение правил не заявляется.

## Проверка и исправления 13.10.2026

Формы перестраиваются в один столбец на мобильных экранах. Повтор ошибок включает вопросы, ситуации и наблюдения. Таймер общей практики не перезапускается до сброса. Новые завершённые тесты автоматически отправляются в общую таблицу; при отсутствии связи сохраняются локально и отправляются позднее. Старые частные попытки остаются частными. Общая таблица содержит последние 100 записей, не является официальным рейтингом. Правила Firestore из файла не развёртываются автоматически через GitHub Pages.
