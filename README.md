# Первая помощь — подготовка команды, 2026

Статический тренажёр для школьников 14–17 лет, Кемь / Карелия. 16 тем, 64 вопроса с объяснениями, 12 ситуаций, 4 наблюдения и 3 практические станции. Авторские учебные задания не являются заданиями чемпионата.

## Запуск и публикация

GitHub Pages: Settings → Pages → Deploy from a branch → main → /root. Сборка и npm не нужны. Все основные зависимости локальные: assets/content.js, core.js, app.js, style.css. Открыть локально можно через `python3 -m http.server 8000`. Старые theory.html, examples.html и test.html направляют в соответствующие разделы.

## Режимы

Перед запуском любого режима обязательны имя/псевдоним и команда. Поля с одними пробелами не принимаются. Введённые данные сохраняются отдельно для каждой попытки и показываются в результате, личной истории, экспорте и при публикации в рейтинге. Изменение профиля во время прохождения не меняет владельца уже начатой попытки.

Тренировка: до 20 вопросов, без ограничения времени, фильтр по теме. Контроль: 20 вопросов / 20 минут. Муниципальная репетиция: 10 вопросов + 3 ситуации по 4 оценки + 2 текстовых наблюдения по 4 оценки / 25 минут. Учебный максимум 62 балла, веса 1/3/2; текстовые наблюдения не заменяют официальное видео и их чтение включено в таймер. Повторение ошибок использует вопросы из последних 10 попыток.

Таймер стартует при запуске, ответы и время фиксируются после завершения. Без ответов ручное завершение запрещено; по таймауту отсутствующие ответы считаются неверными. Никаких бонусов за скорость.

## Источники

Медицинские алгоритмы: учебное пособие Минздрава, Москва, 2025, и приказ №220н. Прямые ссылки и печатные страницы в карточках. Подписанное положение Карелии 2026 подтверждает школьную категорию, состав команды, дистанционный муниципальный и очный основной этап в Медвежьегорске. Подробности заданий и практические чек-листы сверены с типовым проектом правил 2026, вариант 1; подписанная редакция правил Карелии с чек-листами не предоставлена. Это ограничение явно указано на сайте.

## Хранение и Firebase

Личная история и профиль сохраняются в localStorage (`pp_preparation_v2`), доступны экспорт JSON и очистка. Некорректные/старые записи не ломают приложение. Отключение хранилища сопровождается сообщением.

Общий учебный рейтинг в PP.Kem подключается только по запросу пользователя. Конфигурация существующего проекта в assets/config.js. Отображаются только новые записи schemaVersion=2 текущей версии и режима среди последних 100 записей коллекции attempts. Старые записи не удаляются и не смешиваются. HTML-поля выводятся с экранированием. Отправка требует завершённой попытки, псевдонима и согласия на публикацию; ID документа совпадает с ID попытки. Рейтинг вычисляется на клиенте, поэтому не пригоден для официального отбора.

`firestore.rules` — рекомендованный ограничивающий набор правил для новых записей; он НЕ применяется публикацией сайта. Перед применением проверьте остальные коллекции: отсутствующие match запрещают доступ. Требуются Anonymous Auth и права на чтение/создание в attempts. Нет доступа к Firebase Console в рамках этой проверки; фактическое применение правил не заявляется.
